# System Monitor — виджет мониторинга для Windows

Прозрачный оверлей поверх всех окон: видеокарта, процессор, память, диск, сеть.
Один файл `monitor.py`, без драйверов и без прав администратора.

Версия: **1.02**

## Что показывает

| Раздел | Метрики |
|---|---|
| Видеокарта | загрузка, видеопамять, температура, питание, частота ядра, кулер |
| Процессор | загрузка, частота |
| Память | занято/всего, свободно |
| Диск | C: занято/всего, скорость чтения и записи |
| Сеть | скорость ↓/↑, трафик за сессию |
| Прочее | часы |

Набор строк выбирается в меню (шестерёнка), выбор сохраняется.

## Возможности

- Прозрачный фон, скруглённые углы, тянущаяся ширина (260–440 px)
- Положение и ширина запоминаются между запусками
- Глобальный хоткей `Ctrl+Alt+H` (работает из любого окна)
- Язык интерфейса: русский / английский
- Иконка в трее, автозапуск с Windows
- Цвета полосок по нагрузке: зелёный → янтарный → красный
- Пороги температуры GPU: для RTX 3060 — 54/58 °C, для остальных — 72/82 °C
- Журнал событий `events.log` + необязательные уведомления из трея
- Кнопка освобождения памяти (сжатие рабочих наборов процессов)

## Запуск из исходников

```bash
# окружение проекта (на диске G, чтобы не занимать системный)
python -m venv G:/Hermes/venv/widget
G:/Hermes/venv/widget/Scripts/python.exe -m pip install PyQt6 psutil nvidia-ml-py pyinstaller

# запуск
G:/Hermes/venv/widget/Scripts/python.exe monitor.py
```

## Сборка EXE

```bash
G:/Hermes/venv/widget/Scripts/python.exe -m PyInstaller --noconfirm --onefile \
    --windowed --name SystemMonitor --hidden-import pynvml monitor.py
```

Готовый файл: `dist/SystemMonitor.exe` (~35 МБ, зависимостей не требует).

## Файлы рядом с программой

- `settings.json` — выбранные строки, язык, ширина, позиция, уведомления
- `events.log` — события по порогам, появляется при первом срабатывании

Оба файла в git не хранятся: они у каждого свои.

## Требования

- Windows 10/11, 64 бита
- NVIDIA GPU (через NVML из драйвера). Без NVIDIA раздел «Видеокарта» покажет «нет данных»
- Python и .NET для запуска EXE не нужны

## Ограничения

- Температуры процессора нет: в Windows она доступна только через драйвер
  уровня ядра, а виджет работает без драйверов и без прав администратора
- Поддержки AMD/Intel GPU нет — только NVIDIA
- EXE без цифровой подписи, SmartScreen может спросить подтверждение
