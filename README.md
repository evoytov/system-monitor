# System Monitor — виджет мониторинга для Windows

Прозрачный оверлей поверх всех окон: видеокарта, процессор, память, диск, сеть.
Один файл `monitor.py`, без драйверов и без прав администратора.

Версия: **1.03**

## Что показывает

| Раздел | Метрики |
|---|---|
| Видеокарта | загрузка, видеопамять, температура, питание, частота ядра, кулер |
| Процессор | загрузка, температура, частота |
| Память | занято/всего, свободно |
| Диск | C: занято/всего, скорость чтения и записи |
| Сеть | скорость ↓/↑, трафик за сессию |
| Прочее | часы |

Набор строк выбирается в меню (шестерёнка), выбор сохраняется.

## Возможности

- Прозрачный фон, скруглённые углы, тянущаяся ширина (260–440 px)
- Положение и ширина запоминаются между запусками
- Глобальный хоткей `Ctrl+Alt+H` (работает из любого окна)
- Язык интерфейса: русский / английский
- Иконка в трее, автозапуск с Windows
- Цвета полосок по нагрузке: зелёный → янтарный → красный
- Пороги температуры GPU: для RTX 3060 — 54/58 °C, для остальных — 72/82 °C
- Журнал событий `events.log` + необязательные уведомления из трея
- Кнопка освобождения памяти (сжатие рабочих наборов процессов)

## Файлы рядом с программой

- `settings.json` — выбранные строки, язык, ширина, позиция, уведомления
- `events.log` — события по порогам, появляется при первом срабатывании

Оба файла в git не хранятся: они у каждого свои.

## Температура процессора

В Windows температуру CPU нельзя прочитать обычной программе: значения лежат
в регистрах процессора (SMN у AMD), а туда пускает только драйвер.

Виджет читает их сам, через **PawnIO** — подписанный драйвер с открытым кодом
(GPL-2.0, https://pawnio.eu). В комплекте лежит модуль `AMDFamily17.bin`
(LGPL-2.1, текст лицензии — `NOTICE-PawnIO-Modules.txt`), который выполняет
чтение внутри драйвера. Никаких сторонних программ запускать не нужно:
ни HWiNFO, ни LibreHardwareMonitor.

Из регистра `THM_TCON_CUR_TMP` (SMN 0x59800) берётся то же значение, что
показывает HWiNFO как `CPU (Tctl/Tdie)`: биты 21–31, шаг 0.125 °C. Именно
по этой температуре AMD считает троттлинг.

**Условия:**
1. Установлен драйвер PawnIO (ставится один раз, требует прав администратора).
2. Виджет запущен от администратора — иначе драйвер отвечает «доступ запрещён».

Если условия не выполнены, строка «ТЕМПЕРАТУРА CPU» показывает «нет данных»,
а в подсказке при наведении написана причина. Остальные метрики работают всегда.

Автозапуск поэтому сделан через планировщик задач с уровнем «Highest»:
виджет стартует при входе уже с нужными правами, UAC спрашивает один раз —
при включении галочки «Запускать при входе».

## Журнал событий

Пишутся **только температуры** — нагрузка 100 % во время рендера длится часами
и превратила бы журнал в мусор. Событие фиксируется при пересечении порога,
повторно — только после возврата в норму (с запасом 3 °C).

| Датчик | высокая | критическая |
|---|---|---|
| GPU, RTX 3060 | 54 °C | 58 °C |
| GPU, остальные | 72 °C | 82 °C |
| CPU, AMD Ryzen | 80 °C | 90 °C (предел 95 °C) |
| CPU, Intel | 85 °C | 95 °C (предел 100 °C) |

## Требования

- Windows 10/11, 64 бита
- NVIDIA GPU (через NVML из драйвера). Без NVIDIA раздел «Видеокарта» покажет «нет данных»
- Python и .NET для запуска EXE не нужны

## Ограничения

- Температура процессора зависит от HWiNFO: без него строка показывает «нет данных»
- Поддержки AMD/Intel GPU нет — только NVIDIA
- EXE без цифровой подписи, SmartScreen может спросить подтверждение
